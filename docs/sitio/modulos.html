1. Acceso y sesión

Quién
Todos
Código
PantallaContrasena, AuthContext, backend/sesiones.js
Cómo se usa
Abrir, entrar y apagar · Seguridad
  • Se entra con usuario y contraseña. La sesión dura hasta cerrar la pestaña o 8 horas sin uso.
  • Cinco contraseñas malas seguidas bloquean a ese usuario 5 minutos, también si el usuario no existe, para no revelar cuáles existen.
  • Antes de salir, cambiar de pantalla o cerrar la pestaña con datos sin guardar, la app avisa y ofrece Registrar o Salir sin guardar.
  • Una pantalla sin permiso lleva al inicio de cada usuario. Una dirección que no existe muestra Pantalla no encontrada con un botón para volver al inicio (PantallaNoEncontrada).

2. Agregar compra

Ruta
/ (pantalla principal)
Quién
Quien tenga la pantalla Agregar compra
Código
AgregarCompra, BloqueCompra, AsignarMaterial, ResumenCompra
Cómo se usa
Registrar una compra · Un artículo nuevo · Modelo de datos

Por pasos

  1. Al entrar solo se ven la fecha y el proveedor.
  2. Con el proveedor aparece la primera fila.
  3. Con una fila completa (artículo, cantidad, unidad y monto) aparecen la fila punteada + Agregar otro artículo, el subtotal, el IVA, el total, Guardar, Cancelar y Nueva compra.

Lo que todavía no se puede usar no se muestra: no hay botones apagados en gris. Al editar una compra guardada se ve todo de una vez.

Reglas

  • Al escribir el proveedor o el artículo, la opción que más coincide queda marcada y Enter la completa.
  • Solo se sugieren los artículos de las categorías que vende ese proveedor.
  • El precio de la última compra se pone solo. Se escribe el monto o el precio unitario y el otro se calcula; el último que se escribió manda.
  • El IVA (13 %) se suma encima del subtotal. Una compra nueva toma lo que se hizo en la última compra a ese proveedor.
  • Un artículo nuevo abre un formulario para su categoría y sus productos. Ahora no deja guardar y marca la fila con un «!».
  • Guardar pide confirmar con un resumen. Varias compras se registran a la vez con Nueva compra.

3. Lista de compras

Ruta
/compras
Quién
Quien tenga la pantalla. Editar y eliminar son funciones aparte.
Código
PantallaMaestra, DetalleLista, FiltrosEnLinea
Cómo se usa
Lista de compras · Modelo de datos
  • Las compras activas, la más reciente arriba. Tocar una fila abre su detalle para ver, editar o eliminar.
  • Casillas como en el correo: una por compra a la izquierda y otra arriba para elegir todas. La fila elegida cambia de color.
  • Con algo elegido aparece el ícono Eliminar junto a Filtrar. Solo «Agregar compra» lleva texto.
  • Con más de 50 compras la lista va por páginas de 50: «1–50 de 380» y las flechas, arriba, como en el correo. «Elegir todas» elige la página y un aviso ofrece elegir todas las de la lista.
  • Filtrar por proveedor, artículo y rango de fechas, en vivo.
  • El menú ⋮ lleva Exportar datos y Cargar datos.
  • Toda acción se confirma; eliminar varias es todo o nada.

4. Catálogo

Ruta
/catalogo/proveedores, /categorias, /articulos, /productos
Quién
Quien tenga la pantalla; agregar, editar, eliminar, exportar y cargar son funciones aparte
Código
PantallaCatalogo, EditorCatalogo, FichaProveedor, SeleccionCatalogo
Cómo se usa
Catálogo
  • Es la única fuente de las opciones de los buscadores. Cada compra guardada registra en él lo nuevo.
  • Proveedor: con su ficha (ubicación, teléfonos y contactos). Categoría: con los proveedores que la venden. Artículo: con una categoría y ninguno, uno o varios productos. Producto: lo que vende De Panas.
  • Renombrar cambia el nombre también en todas las compras; eliminar deja a las compras con su texto.
  • Un nombre parecido a otro (por ejemplo «Azucar» y «Azúcar») muestra un aviso, sin impedir guardar.
  • Cada sección se exporta (Excel o respaldo) y se carga desde su ⋮, eligiendo qué entra. Cargar nunca borra.

5. Exportar datos

Ruta
/exportar (desde el ⋮ de Lista de compras)
Código
PantallaExportar, utils/exportar.js, shared/gastos.js
Cómo se usa
Exportar y respaldos
  • Rango de fechas (este mes, mes pasado, este año, todo o a mano). Antes de descargar se ve cuántas compras y cuánto dinero entran.
  • Excel (.xlsx): hoja Compras (una fila por artículo, como el Excel del negocio) y hoja Resumen, el reporte de gastos del rango: total, IVA y gasto por proveedor, por categoría y por mes.
  • Respaldo (.json): las compras completas, para Cargar datos en otro equipo.

6. Cargar datos

Ruta
/cargar (desde el ⋮ de Lista de compras)
Código
PantallaCargar, CompararCompra, shared/carga-compras.js
Cómo se usa
Exportar y respaldos
  • Se elige un respaldo .json y qué compras traer.
  • Cada compra es nueva, duplicada (se omite) o modificada: esta se compara lado a lado con la guardada y se elige qué se queda.
  • Es todo o nada. Si la compra guardada cambió mientras se decidía, se avisa y no se pisa.

7. Gestor de usuarios

Ruta
/usuarios
Quién
Solo el administrador
Código
PantallaUsuarios, EditorUsuario, EditorRequisitos, shared/usuarios.js
Cómo se usa
Usuarios y contraseñas · Seguridad
RolPantallasFunciones
Administrador (uno solo)Todas, también las futurasTodas. No se elimina ni cambia de rol.
OperadorTodas menos el gestorTodas (editar y eliminar compras; todo el catálogo)
EmpleadoAgregar compra y Lista de comprasEditar compras
  • El rol trae sus pantallas y funciones; después se ajustan persona por persona.
  • El administrador define los requisitos de contraseña (mínimo de caracteres, mayúscula, minúscula, número y carácter especial), que se revisan en vivo.
  • No se repite el usuario. Las contraseñas se guardan con hash y nunca se comparan con las de otros.

8. Versión .zip y demostración

Código
desktop/ (preparar.mjs, iniciar.mjs, servidor.mjs)
Guía
Instalación en la computadora del cliente
Cómo se usa
Abrir, entrar y apagar
  • Abrir De Panas SV levanta el sistema y lo abre en el navegador como sitio web local (http://localhost:4510), sin internet. Lleva el Node.js oficial firmado para que Windows lo deje abrir.
  • Los datos quedan en %APPDATA%\De Panas SV: borrar o actualizar la carpeta del programa no los toca.
  • Se apaga desde el menú o al cerrar la última pestaña.
  • Abrir De Panas SV (demo) abre aparte (puerto 4511) una copia con dos meses de compras de ejemplo, en su propia carpeta. Nunca toca los datos reales.
  • El .zip trae el manual de uso.
